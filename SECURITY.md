# Sécurité

Pour signaler une faille, utilise le signalement privé de GitHub : onglet **Security** du dépôt, puis **Report a vulnerability**. N'ouvre pas d'issue publique.

Le serveur n'a pas d'authentification et écoute seulement sur `127.0.0.1` par défaut. L'exposer sur un réseau sans proxy authentifié devant n'est pas un usage supporté.
